# Employee Learning & Performance Analytics Dashboard

An end-to-end analytics project focused on employee training, learning participation, performance, and data quality.

## Project Objective

The goal of this project is to analyze employee learning data and create reporting views that help identify training completion, performance patterns, training-hour distribution, and data-quality issues.

## Tools Used

- Microsoft Excel
- SQL
- Power BI
- GitHub

## Dataset

The dataset contains employee training and performance information, including:

- Employee ID
- Employee Name
- Department
- Location
- Job Level
- Training Name
- Training Category
- Training Date
- Training Hours
- Completion Status
- Training Score
- Performance Rating

## Excel Analysis

The Excel dashboard includes:

- Total Employees
- Completed Training
- In Progress Training
- Not Started Training
- Average Training Score
- Total Training Hours
- Average Performance Rating
- Training Completion Rate
- Average Score by Department
- Training Hours by Category
- Data Quality Status

## SQL Analysis

SQL queries were created to analyze:

- Training completion status
- Department performance
- Training hours by category
- Department-level employee counts
- Employees with incomplete training
- Potential data-quality issues

## Power BI Dashboard

The Power BI dashboard is designed to provide:

- Training completion KPIs
- Department performance analysis
- Training category analysis
- Employee learning trends
- Data-quality monitoring
- Interactive filtering

## Data Quality

Data validation was performed to identify:

- Missing or invalid values
- Unusual training scores
- Invalid performance ratings
- Incomplete training records

## Key Business Questions

1. How many employees completed their training?
2. Which departments have higher or lower average scores?
3. Which training categories require the most training hours?
4. How many employees are still in progress or have not started?
5. Are there any data-quality issues?
6. What patterns can be identified from employee learning and performance data?
